# Example skill

Replace this template with a focused workflow before adding it to `skills/`.

## Workflow

1. Identify the required inputs and the intended outcome. State when missing
   information needs a user decision rather than an assumption.
2. Perform the task using explicit steps. Resolve bundled paths relative to
   this skill's directory.
3. Verify the outcome with concrete evidence. Define what success looks like
   and what to report if the task is blocked.

## Supporting material

Add references only when the workflow needs them. Keep optional scripts in
`scripts/`, detailed guidance in `references/`, and reusable files in `assets/`.
