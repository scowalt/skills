# skills

Read [CONTRIBUTING.md](CONTRIBUTING.md) before adding or changing skills. Read
[the convention research](docs/conventions.md) before changing the collection's
format or Pi packaging.

Run `mise run check` before finalizing changes. For a real skill, also exercise
a representative request: metadata validation alone does not prove that its
workflow succeeds.

Publish only original or compatibly licensed material. Keep credentials and
private operational details external to the public collection.

Mission Control owns this GitHub repository's settings through OpenTofu;
change the infrastructure there rather than through the GitHub UI.
